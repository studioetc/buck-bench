# Operation Black Buck — Aerial Refuelling Simulation

Interactive map animation of the **Black Buck 1** tanker chain (30 Apr–1 May 1982): Ascension Island → Port Stanley → return RV off Brazil.

## Run

Open `index.html` in a browser (no build step, no server required):

```bash
open index.html
```

## Views

| View | Purpose |
|------|---------|
| **Overview** | Full South Atlantic track, places, peel-offs |
| **Formation (scaled)** | Package zoom with lateral spacing exaggerated ~50× so probe-and-drogue links are readable |
| **Split** | Both at once |

## Controls

- **Play / Pause**, **Reset**, **Next event**
- Timeline scrubber (markers = major mission events)
- Speed: 30×–600× mission time

## What it shows

- 11 Victor K.2 tankers + 2 Vulcans launching from Wideawake
- Primary abort (XM598 / Reeve) → XM607 (Withers) takes the strike
- Cascading brackets: Victors refuel Victors and the Vulcan, then peel north
- Final storm bracket: Biglands probe failure, Tuxford’s critical top-up
- Solo bomb run (**SUPERFUSE**) and return refuel (Neal) + Tuxford rescue (Seymour)

## Notes

Illustrative reconstruction for education/visualization — not an official RAF chart. Geometry, fuel figures, and exact peel points are simplified for clarity while following public accounts (RAF histories, *Vulcan 607*, mission narratives).
