About the archive

Outputs, not a leaderboard.

These artifacts were recovered from local sessions and grouped by recorded model evidence. Some are revisions from the same run; the version controls keep those outputs together.

Prompts, tooling, harnesses and working conditions differed between runs. This is a visual archive for exploration, not a controlled evaluation or a claim about model quality.
